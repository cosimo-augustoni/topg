UI concept · game · enhancement

Double points on the last questions of a board

The host turns on one session-wide rule: once only X unanswered questions are left on the current board, those questions are worth double. It's on by default with X = 3. The rule lives only in the running session, so no data is stored in the quiz template.

Data model plan

Nothing is persisted, not even in the host's browser: every new session starts at on/3. The rule sits next to the other per-session state (TimerState, BuzzerState) and the doubled value is derived when it is needed, so it never goes stale. Because answered questions never count as doubled, their tiles fall back to normal points without any extra state.

New: DoublePointsState

topg.Web/Quiz/Execution/DoublePointsState.cs 
public class DoublePointsState
{
    public const int DefaultLastQuestions = 3;

    public bool IsEnabled { get; set; } = true;
    public int LastQuestions { get; set; } = DefaultLastQuestions;
}

QuizSession: state, setter, point calculation

topg.Web/Quiz/Execution/QuizSession.cs 
+ public DoublePointsState DoublePointsState { get; } = new();

+ public void SetDoublePoints(bool isEnabled, int lastQuestions)
+ {
+     DoublePointsState.IsEnabled = isEnabled;
+     DoublePointsState.LastQuestions = Math.Max(1, lastQuestions);
+     SessionStateHasChanged();
+ }

+ public bool IsDoubled(Question q) =>
+     DoublePointsState.IsEnabled && !q.IsAnswered
+     && Quiz.CurrentBoard.UnansweredCount
+        <= DoublePointsState.LastQuestions;

+ public int PointsFor(Question q) =>
+     IsDoubled(q) ? q.Points * 2 : q.Points;
